# Netflix_Clone
A responsive clone of the Netflix website built using HTML and CSS, focusing on modern UI design and layout.

This project is a **responsive clone of the Netflix website** built using **HTML** and **CSS**, focusing on modern UI design and clean layout structure across different screen sizes.

## 🚀 Features
- Fully responsive design (desktop, tablet, and mobile)
- Modern Netflix-inspired UI
- Clean and structured HTML
- Styled using pure CSS (no frameworks)

## 🛠️ Technologies Used
- HTML5
- CSS3

## 🎯 Project Objective
This project was created to:
- Practice responsive web design
- Improve frontend layout and styling skills
- Understand real-world website structure
